위상반전 실험실

마이크로 들어오는 소리를 실시간으로 뒤집어서(위상반전) 스피커로 내보냅니다. 화면 아래에서 실제 왕복 지연시간도 측정할 수 있어요 — 왜 완전한 소음상쇄가 안 되는지 숫자로 확인 가능.

마이크 입력 반전 출력
대기중
시스템 레이턴시 (추정)
—
실측 왕복 지연
— ms
위상반전
출력 볼륨 15%
지연 보정 0 ms
주의: 마이크와 스피커가 서로 가까우면 되먹임(하울링)이 생길 수 있어요. 이어폰 사용을 권장하고, 처음엔 출력 볼륨을 낮게 두고 천천히 올리세요. 날카로운 소리가 나면 바로 정지하세요.
왜 완전히 상쇄되지 않을까
화면 위 실측값이 곧 답입니다. 폰 마이크 → 처리 → 스피커까지 걸리는 시간은 보통 수십 ms. 사람이 듣는 소리 대부분(수백 Hz 이상)은 한 주기가 몇 ms밖에 안 되기 때문에, 반전된 파형이 도착했을 땐 이미 원래 소리가 지나간 뒤예요. 그래서 진짜 자동차 ANC는 헤드레스트에 마이크를 박고 전용 저지연 칩으로 처리합니다 — 이 실험은 그 이유를 몸으로 느껴보는 용도예요.
